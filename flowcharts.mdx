---

### Diagram Alur Dasar

```mermaid
flowchart TD
    A[Mulai] --> B{Apakah berfungsi?}
    B -->|Ya| C[Berfungsi!]
    B -->|Tidak| D[Debug]
    D --> B
    C --> E[Selesai]
```

### Contoh Pohon Keputusan

```mermaid
flowchart TD
    A[Permintaan User] --> B{Perlu Akses API?}
    B -->|Ya| C[Periksa Kredensial]
    B -->|Tidak| F[Proses Permintaan]
    C --> D{Kredensial Valid?}
    D -->|Ya| F[Proses Permintaan]
    D -->|Tidak| E[Return Error]
    F --> G[Return Response]
    E --> H[Selesai]
    G --> H[Selesai]
```

### Alur Proses

```mermaid
flowchart LR
    A[Input Data] --> B[Validasi]
    B --> C[Transform]
    C --> D[Simpan]
    D --> E[Validasi]
    E --> F[Selesai]
```

## Diagram Alur Bertingkat

```mermaid
flowchart TB
    classDef frontend fill:#e1f5fe,stroke:#01579b,stroke-width:2px, color:#000000
    classDef backend fill:#f3e5f5,stroke:#4a148c,stroke-width:2px, color:#000000
    
    subgraph "Frontend"
        A[Aplikasi React] --> B[API Call]
    end
    
    subgraph "Backend"
        C[API Gateway] --> D[Lambda Function]
        D --> E[Database]
    end
    
    B --> C
    E --> D
    D --> C
    C --> B
    
    class A,B frontend
    class C,D,E backend
```

### Alur Kerja Kompleks

```mermaid
flowchart TD
    Start([Mulai]) --> Input[/Input User/]
    Input --> Validate{Validasi Input}
    Validate -->|Tidak Valid| Error[Tampilkan Error]
    Error --> Input
    Validate -->|Valid| Process[Proses Data]
    Process --> Save[(Simpan ke Database)]
    Save --> Success{Berhasil Disimpan?}
    Success -->|Tidak| Retry[Coba Lagi]
    Retry --> Save
    Success -->|Ya| Notify[Kirim Validasi]
    Notify --> End([Selesai])
```

## Referensi Sintaks Diagram Alur

### Bentuk Node

| Bentuk          | Sintaks     | Kasus Penggunaan |
| --------------- | ----------- | ---------------- |
| Persegi Panjang | `A[Teks]`   | Proses/Aksi      |
| Belah Ketupat   | `A{Teks}`   | Keputusan        |
| Lingkaran       | `A((Teks))` | Mulai/Selesai    |
| Stadium         | `A([Teks])` | Mulai/Selesai    |
| Silinder        | `A[(Teks)]` | Database         |
| Jajaran Genjang | `A[/Teks/]` | Input/Output     |

### Jenis Koneksi

| Jenis       | Sintaks    | Deskripsi      |     |                  |
| ----------- | ---------- | -------------- | --- | ---------------- |
| Panah       | `A --> B`  | Alur standar   |     |                  |
| Berlabel    | \`A --\>   | Label          | B\` | Koneksi berlabel |
| Putus-putus | `A -.-> B` | Opsional/Async |     |                  |
| Tebal       | `A ==> B`  | Alur penting   |     |                  |
