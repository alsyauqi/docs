# Diagram Alur

Diagram alur adalah alat visual yang powerful untuk menjelaskan proses kompleks, pohon keputusan, dan alur kerja. Panduan ini menunjukkan cara membuat dan mengintegrasikan diagram alur ke dalam dokumentasi Anda.

## Ringkasan

Diagram alur dapat dibuat menggunakan berbagai metode:

- Diagram Mermaid (direkomendasikan)
- Alat diagram eksternal
- Embed gambar
- Diagram interaktif

## Diagram Alur Mermaid

Mermaid adalah cara paling populer untuk membuat diagram alur dalam dokumentasi. Menggunakan sintaks teks sederhana untuk menghasilkan diagram yang indah.

### Diagram Alur Dasar

```mermaid
flowchart TD
    A[Mulai] --> B{Apakah berfungsi?}
    B -->|Ya| C[Berfungsi]
    B -->|Tidak| D[Debug]
    D --> B
    C --> E[Selesai]
```

### Contoh Pohon Keputusan

```mermaid
flowchart TD
    A[Permintaan User] --> B{Perlu Akses API?}
    B -->|Ya| C[Periksa Kredensial]
    B -->|Tidak| F[Proses Permintaan]
    C --> D{Kredensial API Valid?}
    D -->|Ya| F[Proses Permintaan]
    D -->|Tidak| E[Return Error]
    F --> G[Return Response]
    E --> H[Selesai]
    G --> H[Selesai]
```

### Alur Proses

```mermaid
flowchart Gateway
    A[Kirim Data] --> B[Validasi]
    B --> C[Transform Data]
    C --> D[Simpan]
    D --> E[Selesai]
```

## Diagram Alur Interface

```mermaid
flowchart TB
    classDef frontend fill:#e1f5fe,stroke:#01579b,stroke-width:2px
    classDef backend fill:#f3e5f5,stroke:#4a148c,stroke-width:2px
    
    subgraph "Frontend"
        A[Aplikasi React] --> B[API Call]
    end
    
    subgraph "Backend"
        C[API Gateway] --> D[Lambda Function]
        D --> E[Database]
    end
    
    B --> C
    E --> D
    D --> C
    C --> B
    
    class A,B frontend
    class C,D,E backend
```

### Alur Kerja Kompleks

```mermaid
flowchart TD
    Start([Mulai]) --> Input[/Input User/]
    Input --> Validate{Validasi Input}
    Validate -->|Tidak Valid| Error[Tampilkan Error]
    Error --> Input
    Validate -->|Valid| Process[Proses Data]
    Process --> Save[(Simpan ke Database)]
    Save --> Success{Berhasil Disimpan?}
    Success -->|Tidak| Retry[Coba Lagi]
    Retry --> Save
    Success -->|Ya| Notify[Kirim Validasi]
    Notify --> End([Selesai])
```

## Referensi Sintaks Diagram Alur

### Bentuk Node

| Bentuk          | Sintaks     | Kasus Penggunaan |
| --------------- | ----------- | ---------------- |
| Persegi Panjang | `A[Teks]`   | Proses/Aksi      |
| Belah Ketupat   | `A{Teks}`   | Keputusan        |
| Lingkaran       | `A((Teks))` | Mulai/Selesai    |
| Stadium         | `A([Teks])` | Mulai/Selesai    |
| Silinder        | `A[(Teks)]` | Database         |
| Jajaran Genjang | `A[/Teks/]` | Input/Output     |

### Jenis Koneksi

| Jenis       | Sintaks    | Deskripsi      |     |                  |
| ----------- | ---------- | -------------- | --- | ---------------- |
| Panah       | `A --> B`  | Alur standar   |     |                  |
| Berlabel    | \`A --\>   | Label          | B\` | Koneksi berlabel |
| Putus-putus | `A -.-> B` | Opsional/Async |     |                  |
| Tebal       | `A ==> B`  | Alur penting   |     |                  |

## Contoh Interaktif

<CodeGroup>

```mermaid Proses Sederhana
flowchart TD
    A[Mulai] --> B[Proses]
    B --> C[Selesai]
```


```mermaid Dengan Keputusan
flowchart TD
    A[Mulai] --> B{Keputusan}
    B -->|Ya| C[Aksi A]
    B -->|Tidak| D[Aksi B]
    C --> E[Selesai]
    D --> E
```


```mermaid Alur Kompleks
flowchart TB
    subgraph "Layer User"
        U[User] --> UI[User Interface]
    end
    
    subgraph "Layer Aplikasi"
        UI --> API[API Gateway]
        API --> AUTH[Autentikasi]
        API --> BL[Business Logic]
    end
    
    subgraph "Layer Data"
        BL --> DB[(Database)]
        BL --> CACHE[(Cache)]
    end
```

</CodeGroup>

## Tips Integrasi

### Dalam Dokumentasi

- Tempatkan diagram alur dekat dengan konten teks yang relevan
- Gunakan callout untuk menyoroti poin keputusan penting
- Sediakan versi yang dapat diunduh untuk presentasi

### Version Control

- Simpan kode sumber diagram dalam version control
- Gunakan pesan commit yang bermakna untuk perubahan diagram
- Pertimbangkan review diagram sebagai bagian dari review dokumentasi

<Warning>
  Diagram alur yang besar atau kompleks dapat mempengaruhi waktu loading halaman. Pertimbangkan menggunakan alat diagram eksternal untuk workflow yang sangat detail.
</Warning>
